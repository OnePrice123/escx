# Знак brink.watch

Знак не придуман отдельно от продукта. Главный элемент интерфейса — дуга,
которая разгорается к текущему значению и заканчивается угольком. Знак — это
она же, сведённая к минимуму. Точка в `brink·watch` — тот же уголёк, поэтому
знак и написание оказываются одним объектом, а не двумя.

Посмотреть всё сразу: откройте **`logo.html`** двойным кликом.

## Файлы

| Файл | Где применяется |
|---|---|
| `mark.svg` | основной знак, светлый фон |
| `mark-dark.svg` | тёмный фон: пепельный конец осветлён, иначе дуга тонет |
| `mark-mono.svg` | одноцветный, наследует `currentColor` — печать, штампы, факсимиле |
| `logo.svg` | знак + слово, для шапок писем и презентаций |
| `favicon.svg` | вкладка браузера |
| `icon-32/180/512.png` | браузеры без SVG-иконок, iOS, установка на домашний экран |
| `og-cover.png` | превью ссылки в мессенджерах и соцсетях |
| `mark-open/ring/short.svg` | три варианта формы; выбран `open` |

## Пересборка

```bash
python3 brand/make_logo.py     # SVG, только стандартная библиотека
python3 brand/rasterize.py     # PNG, нужен playwright + chromium
```

`make_logo.py` держится на голой стандартной библиотеке намеренно: его может
понадобиться прогнать в CI. Растеризация требует настоящего браузера и потому
живёт отдельно — её запускают руками, а результат коммитят.

## Правила

- **Мелкая версия — не уменьшенная большая.** На 16 пикселях градиент и свечение
  превращаются в грязное пятно, а тонкая дуга радиусом 31 — в еле заметный крючок.
  Фавикон рисуется компактнее и вдвое толще: `r=26, sw=20`, один цвет, без свечения.
  Силуэт тот же.
- **Уголёк всегда на конце дуги**, а не в середине и не отдельно. Он показывает,
  докуда дошла шкала; оторванный от дуги, он перестаёт что-либо значить.
- **Знак не поворачивают, не отражают и не обводят.** Разрыв внизу — часть смысла:
  шкала не замкнута, движение не закончено.
- **Цвет не единственный носитель.** Grayscale-версия обязана оставаться узнаваемой —
  проверяется кнопкой «Убрать цвет» в `logo.html`.
- Оранжевый `#C4703B` — акцент, а не фон. Заливать им плашки нельзя: он занят
  под значение шкалы, и на сайте это означает «горячо».
