# escx-ingest

Стартовый набор для сбора данных о межгосударственных конфликтах.
Часть проекта Escalation Index. Подробности — в документе «Сбор данных: чем и как».

## Нулевые зависимости

Только стандартная библиотека Python 3.11+. Ставить нечего, `pip install` не нужен.
Хранилище — SQLite. Для 60 диад этого хватает с большим запасом; схема переносится
в Postgres заменой трёх типов.

## Запуск

```bash
python3 tests/test_offline.py                 # 46 проверок пайплайна, сеть не нужна
python3 tests/test_llm_offline.py             # 53 проверки LLM-контура, сеть не нужна
python3 -m escx.cli init                      # схема + реестр диад
python3 -m escx.cli backfill-ucdp --start 2020-01-01 --end 2024-12-31
python3 -m escx.cli pull-gdelt --slices 8     # последние 2 часа потока GDELT
python3 -m escx.cli status
```

Начните с короткого диапазона в `backfill-ucdp`: если формат ответа где-то разойдётся
с ожиданиями, это вылезет сразу и на маленьком объёме.

## Что внутри

| Файл | Назначение |
|---|---|
| `escx/codes.py` | соответствие GW ↔ CAMEO ↔ ISO3. Источники используют разные системы кодов, и это ловушка №1 |
| `escx/http.py` | ретраи, экспоненциальный бэкофф, дисковый кэш |
| `escx/db.py` | схема SQLite; `raw_events`, `phase_log`, `forecasts` защищены триггерами от UPDATE и DELETE |
| `escx/match.py` | сопоставление событий с диадами: rule → geo → llm, с измерением доли несопоставленных |
| `escx/indicators.py` | робастная нормализация (медиана/MAD), накал, классификация темпа |
| `escx/sources/ucdp.py` | GED через REST API |
| `escx/sources/gdelt.py` | 15-минутный файловый поток + шаблон запроса BigQuery с dry_run |
| `escx/sources/simple.py` | GPR, санкционные списки, голосования ГА ООН, SIPRI, NOTAM |
| `escx/llm/rubric.py` | якорная рубрика 0–4 с наблюдаемыми признаками и примерами |
| `escx/llm/schema.py` | строгая схема ответа; полей probability и forecast в ней нет намеренно |
| `escx/llm/budget.py` | дневной лимит расходов, персистентный, бросает исключение при превышении |
| `escx/llm/provider.py` | MockProvider для офлайн-тестов, OpenAI-совместимый для облака и локальной модели |
| `escx/llm/extract.py` | prefilter → cache → budget → LLM → validate → store |
| `escx/llm/eval.py` | каппа Коэна, взвешенная каппа, F1, тест устойчивости, правило допуска |

## Инварианты, которые нельзя нарушать

1. `raw_events`, `phase_log`, `forecasts` — только INSERT. Это триггеры БД, а не соглашение.
2. Идемпотентность: естественный ключ `(source, source_id)`, повторный прогон безопасен.
3. Несопоставленные события считаются, а не выбрасываются. Рост доли `unmatched` — сигнал поломки.
4. ACLED не используется: его условия запрещают проекты нашего типа. См. раздел 7.1 методологии.
5. **Модель извлекает факты из текста. Модель не производит вероятность.** Вероятность
   считает статистическая модель, обученная на исторических исходах и проверяемая по Brier.
6. Каждое утверждение модели подтверждается дословной цитатой из исходного текста.
   Не найдена цитата — ответ отбраковывается целиком, а не «чинится».
7. LLM-индикатор попадает в индекс только после того, как согласие с ручной разметкой
   пройдёт порог: `python3 -m escx.cli llm-eval --gold gold.json --pred pred.json`

## Лицензии источников

UCDP, GDELT — свободно. GPR — CC BY, атрибуция обязательна. SIPRI — атрибуция.
Санкционные реестры — публичные. Страница «Источники и лицензии» на сайте обязательна.
