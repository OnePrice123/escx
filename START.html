1

Завести аккаунт GitHub

3 минуты · бесплатно, карта не нужна

Это «облачная папка» для кода. Там же будет бесплатно работать робот, который раз в сутки собирает свежие данные.

  1. Открыть github.com/signup
  2. Ввести почту, придумать пароль и имя пользователя
  3. Подтвердить почту по письму
Если аккаунт уже есть — просто войдите и переходите к шагу 2.
2

Положить проект на GitHub

7 минут · бесплатно

Самый простой способ — через бесплатную программу GitHub Desktop. Терминал и команды не нужны.

  1. Распаковать escx.zip — получится папка escx
  2. Скачать и установить GitHub Desktop, войти своим аккаунтом
  3. В программе: File → Add local repository → выбрать папку escx
  4. Нажать Publish repository
  5. Снять галочку «Keep this code private» — репозиторий должен быть публичным
  6. Нажать Publish repository ещё раз
Галочку снимаем не из идеализма: у публичного репозитория робот работает без ограничения по времени и бесплатно, у приватного — 2000 минут в месяц. Плюс открытая методология и есть главный аргумент этого продукта.

Если привычнее терминал — три команды вместо всего перечисленного:

cd escx
gh repo create escx --public --source=. --push
3

Включить робота, который собирает данные

1 минута · бесплатно

GitHub по умолчанию не запускает автоматику в свежем репозитории — надо один раз разрешить.

  1. Открыть свой репозиторий на github.com
  2. Вкладка Actions
  3. Нажать зелёную кнопку I understand my workflows, go ahead and enable them
Дальше он работает сам: раз в час забирает свежие новости, раз в сутки пересчитывает индекс. Ничего запускать руками не нужно.
4

Подключить хостинг Cloudflare Pages

7 минут · бесплатно, карта не нужна

Это то, что показывает сайт людям. Выбран не случайно: у GitHub Pages и Vercel в правилах прямо запрещено вести на бесплатном тарифе бизнес, а у вас в планах платные подписки. У Cloudflare такого запрета нет.

  1. Зарегистрироваться на dash.cloudflare.com
  2. В левом меню: Compute (Workers & Pages)
  3. Create → вкладка Pages → Connect to Git
  4. Разрешить доступ к GitHub, выбрать репозиторий escx
  5. Заполнить три поля и больше ничего не трогать:
Build command:            python3 web/build.py
Build output directory:   site
Variable  PYTHON_VERSION = 3.11
  1. Нажать Save and Deploy и подождать пару минут
Переменная PYTHON_VERSION добавляется в разделе Environment variables на той же странице настроек сборки.
Что получится

Работающий сайт по адресу escx.pages.dev

Открывается у кого угодно, работает по защищённому соединению, обновляется сам. Дальше вам не нужно делать ничего: робот собирает данные, хостинг пересобирает страницу. Каждое изменение в проекте автоматически появляется на сайте через минуту.

Первое время сайт покажет плашку «демонстрационные данные» — это честно и так задумано. Как только робот накопит настоящие, плашка сменится сама.

Сколько это стоит
Хостинг сайта$0 Робот, собирающий данные$0 Адрес escx.pages.dev$0 Источники данных — UCDP, GDELT$0 Итого в месяц$0.00
Что можно спокойно не делать сейчас

Это единственные места, где появляются деньги. Ни одно из них не нужно для запуска.

Свой домен вместо escx.pages.dev~$12 в год Умный разбор новостей нейросетью~$60 в месяц Загрузка старых новостей из архива Googleот $0

Без нейросети часть показателей будет пустой — и сайт честно покажет это серым цветом и подписью «нет данных». Это лучше, чем красивая цифра, за которой ничего нет. Включить можно потом, одной настройкой.

Чего за ноль не будет

Платных подписок и личного кабинета. Чтобы принимать деньги, нужно место, где хранится «кто что оплатил», а у бесплатного сайта такого места нет. Это следующий шаг — и делать его стоит не раньше, чем найдётся первый желающий заплатить.

Писем с оповещениями. По той же причине. Тоже решается бесплатно, но позже.
